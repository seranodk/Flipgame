# Vendespil

Vendespil (memory) for børn fra 4 til 8 år. Vend to kort ad gangen og find parrene. Kører i browseren på både mobil og computer — ét `index.html`, ingen afhængigheder.

**Aktuel version: Vendespil 0.1.0**

## Spil som app (fuld skærm)
Åbn spillet på GitHub Pages på mobilen og vælg **Føj til hjemmeskærm** (Safari: Del-knappen, Chrome: menuen ⋮). Så starter det i fuld skærm uden browserlinje og kan spilles offline. På Android kan du også trykke på fuldskærmsknappen øverst.

## Spil
- Tryk på et kort for at vende det. Passer de to kort sammen, bliver de liggende.
- Passer de ikke, vender de om af sig selv efter lidt over et sekund — eller med det samme, når man trykker på næste kort.
- Ingen tid og intet at tabe. Til sidst får man 1–3 stjerner efter antal træk, og rekorden for hver størrelse gemmes.
- **2 spillere:** finder man et par, må man tage en tur mere. Bordets kant og topbaren viser, hvis tur det er.

## Valg i menuen
- **Billeder:** Dyr · Frugt · Trafik · Havet · Natur · Mad · Sport · Eventyr · Kryb · Hjemme — eller Blandet.
- **Størrelse:** 4×4 (standard), 5×5 (midterkortet er en fri stjerne) eller 6×6.
- **Spillere:** 1 eller 2.

## Versioner
Navngivning: **Vendespil 0.x.x** — større ændring hæver første x, mindre ændring hæver andet x.

### Vendespil 0.1.0
- Første version: 10 kategorier à 18 billeder, 3 størrelser, 1–2 spillere, stjerner, rekord, lyd, konfetti, app-installation og fuld skærm.
